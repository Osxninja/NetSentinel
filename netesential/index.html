ENGINEERING PIPELINE

The Six-Stage Data Lifecycle

From the network interface card to executive-ready incident deliverables without lock contention.

Stage 1: Zero-Privilege Packet Ingestion

Captures raw packets at line rate using Scapy with BPF kernel filters (ip or vlan). If the host lacks Npcap/libpcap drivers or administrative privileges, NetSentinel automatically switches to zero-privilege connection polling using psutil.net_connections, guaranteeing continuous monitoring across unprivileged endpoints.

  • Pure Python protocol pruning: Extracts IP, TCP, UDP, and ICMP headers in memory.
  • Hardware thread isolation: Ingestion runs on a dedicated thread, immune to analytical latency.
  • Thread-safe ring buffer: Decouples packet arrival from disk writes via queue.Queue(maxsize=10000).

Stage 2: Double-Buffered WAL Queue

Direct disk writes during traffic spikes cause SQLite database locks. NetSentinel's AsyncBatchWriter pools records into micro-batches of 250 packets or 500ms intervals, executing bulk multi-row inserts through aiosqlite.

  • PRAGMA journal_mode=WAL: Enables concurrent reader and writer transactions without locks.
  • PRAGMA synchronous=NORMAL: Eliminates disk sync bottlenecks while maintaining durability.
  • Zero drop rate: Double-buffered queue drains smoothly under heavy Poisson bursts.

Stage 3: Tri-Tier Analytic Engine

Combines deterministic rules, non-parametric statistics, and machine learning to maximize true positive rates while suppressing false alarms:

  • Stage 1 (Rules): Detects volumetric spikes (T1498), port sweeps >20 unique ports (T1046), and SYN/RST floods (T1499).
  • Stage 2 (Statistics): Calculates rolling Median Absolute Deviation (MAD) modified Z-scores (M_i > 3.5) with a 500-packet learning warmup period.
  • Stage 3 (Machine Learning): Fits an online Isolation Forest on 10D multivariate vectors, scaling outlier scores through a sigmoid probability function (P >= 0.70).

Stage 4: Autonomous (EC)² Multi-Agent Graph

When an anomaly is flagged, the (EC)² (Explainable Cybersecurity Consensus) directed graph activates 8 specialized agents that formulate, test, and refine hypotheses without hallucination:

  • Agents 1–3 (Hypothesis Generation): Propose multiple competing root-cause hypotheses (benign admin scan vs C2 beaconing).
  • Agents 4–6 (Evidence Collection): Execute read-only SQL queries on historical flow logs and inspect network topology.
  • Agents 7–8 (Review & Synthesis): Conduct adversarial review and synthesize a formal, plain-English incident report.

Stage 5: Evidence Grounding & PII Redaction

Autonomous agents are prohibited from making ungrounded claims. Every assertion must cite a concrete SQL log row or topology graph entity.

  • Knowledge Graph Traversal: Validates host asset roles (e.g. Finance Workstation vs Database Server).
  • Automated PII Masking: Redacts authorization tokens, credentials, and sensitive payload fragments.
  • Strict SQL Sandboxing: Read-only query execution prevents injection or state tampering.

Stage 6: Visual SOC Dashboard & Deliverables

NetSentinel serves an interactive Streamlit SOC dashboard at http://localhost:8501 providing complete real-time visibility:

  • Wireshark-Style Packet Dissector: Real-time tabular inspector with protocol, port, and flag filters.
  • Endpoint Hardware Telemetry: Live gauges for CPU, memory, interface I/O, and socket handles.
  • One-Click PCAP Export: Dump captured ring-buffer flows to standard PCAP for Wireshark analysis.

CAPABILITIES

Engineered for Autonomous Defense

Built from the ground up for high throughput, statistical resilience, and zero hallucination.

⚡

Zero-Privilege Ingestion

Bypasses the requirement for raw-socket root/Administrator rights using an automatic fallback to connection polling via psutil, running smoothly on restricted endpoints.

📊

Rolling MAD Baselines

Replaces fragile Gaussian standard deviation with non-parametric Median Absolute Deviation, resisting distortion from Poisson bursts and scheduled backups.

🧠

10D Isolation Forest ML

Unsupervised machine learning trained on multivariate vectors including port entropy, inter-arrival time variance, and TCP flag distributions to catch zero-days.

🤖

(EC)² Multi-Agent Graph

An 8-agent directed investigation graph autonomously formulates 3 competing hypotheses, tests them against historical SQL logs, and writes plain-English incident deliverables.

💾

SQLite WAL High-Concurrency

High-throughput double-buffered async micro-batching (250 pkts / 500ms) with WAL mode pragmas prevents database locks during heavy network floods.

🖥️

Visual SOC Dashboard

Streamlit web dashboard with Wireshark-style tabular packet dissector, live CPU/RAM/interface telemetry gauges, and forensic report reader.
